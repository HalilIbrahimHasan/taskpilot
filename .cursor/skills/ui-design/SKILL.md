# UI Design

- Use the existing indigo/slate visual language and shadcn-style local primitives.
- Establish clear hierarchy with restrained cards, spacing, typography, and color.
- Design desktop and mobile states together.
- Include loading, empty, error, success, and destructive-action states.
- Use semantic HTML, labels, visible focus, sufficient contrast, and keyboard access.
- Keep automation selectors limited to key controls.

Verify the rendered page visually and through its accessibility tree at representative widths.
